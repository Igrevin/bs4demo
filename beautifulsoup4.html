Python / HTML parser

把凌亂的網頁，煮成資料。

Beautiful Soup 4 是 Python 的 HTML、XML 解析工具。它不替你發送請求，卻能把拿到手的標記文件，變成容易搜尋、導覽與修改的 Python 物件。

# Hello, soup!

01 / First taste

先把文件交給 Soup

先安裝套件，再選擇解析器。對一般 HTML，Python 內建的 html.parser 已經夠用；若需要更快的解析速度，可以安裝 lxml。

安裝 Beautiful Souppip install beautifulsoup4
可選：更快的解析器pip install lxml

建立第一個 BeautifulSoup 物件

from bs4 import BeautifulSoup

html = "<html><body><h1>我的文章</h1></body></html>"
soup = BeautifulSoup(html, "html.parser")

print(soup.title)       # 找到第一個 title
print(soup.h1.get_text())  # 取出標題文字
Beautiful Soup 只負責解析字串或檔案。要讀取網頁，通常先用 requests 取得 HTML，再交給 Soup。
02 / Navigate

搜尋你需要的節點

Soup 提供直覺的搜尋 API。先從最常用的 find() 與 find_all() 開始，再用 CSS selector 處理更複雜的結構。

# 找到第一個符合的標籤
first_link = soup.find("a")

# 找到所有 article 標籤
articles = soup.find_all("article")

# 依 class 或 id 篩選
news = soup.find_all("div", class_="news-card")
main = soup.find(id="main-content")

# CSS selector：像寫 CSS 一樣搜尋
prices = soup.select("article.product > .price")
方法用途結果
find()找到第一個符合節點Tag 或 None
find_all()找到所有符合節點ResultSet
select()用 CSS selector 搜尋ResultSet
find_parent()往上找父層Tag 或 None
03 / Extract

把標籤變成乾淨資料

找到節點後，最常見的任務是取出文字與 HTML 屬性。注意：get_text() 適合呈現給人看的文字，string 在節點有多層子標籤時可能是 None。

link = soup.find("a")

# 取文字，並清理前後空白
title = soup.get_text(" ", strip=True)

# 取屬性：字典形式或快捷寫法
url = link["href"]
css_class = link.get("class", [])

# 將所有連結整理成資料列
rows = [
    {"text": a.get_text(strip=True), "url": a.get("href")}
    for a in soup.select("a[href]")
]
空值要防守使用 tag.get() 或先判斷 Tag 是否存在，避免資料缺欄時拋出 AttributeError。
相對網址要補全搭配 urllib.parse.urljoin()，把 /article/1 轉成完整網址。
04 / Transform

清理、修改，再輸出

Beautiful Soup 不只能讀，也能修改樹狀結構。這很適合移除廣告、重新命名標籤，或在保存前清理不需要的內容。

# 移除不需要的節點
for ad in soup.select(".advertisement, script, style"):
    ad.decompose()

# 修改文字與屬性
soup.h1.string = "清理後的標題"
image = soup.find("img")
if image:
    image["alt"] = "文章封面"

# 輸出乾淨 HTML 或純文字
clean_html = soup.prettify()
plain_text = soup.get_text("\\n", strip=True)
05 / Field notes

進階：從一頁走向一批資料

真正的資料擷取通常包含網路請求、分頁、選擇器失效與資料保存。把每一步拆開，程式會更容易測試，也更容易修正。

搭配 requests 與分頁

import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin

headers = {"User-Agent": "Mozilla/5.0 (compatible; MyBot/1.0)"}
url = "https://example.com/news"

response = requests.get(url, headers=headers, timeout=10)
response.raise_for_status()
soup = BeautifulSoup(response.text, "html.parser")

for card in soup.select("article.card"):
    title = card.select_one("h2")
    href = card.select_one("a[href]")
    if title and href:
        item = {
            "title": title.get_text(" ", strip=True),
            "url": urljoin(url, href["href"]),
        }
        print(item)
尊重網站規則先查看 robots.txt、服務條款與網站負載，設定合理的請求間隔，不要繞過登入或存取限制。
動態內容的邊界Soup 不會執行 JavaScript。若 HTML 由瀏覽器執行後才出現，需找 API 或使用 Playwright 等瀏覽器工具。
解析器要選對HTML 使用 html.parser 或 lxml；XML 可使用 lxml-xml，避免用錯解析器造成結構差異。
大型文件要節制縮小選擇範圍、少用全文件搜尋，必要時先用 lxml 做高效解析再處理。

穩健的錯誤處理

try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
except requests.RequestException as error:
    print(f"請求失敗：{error}")
else:
    soup = BeautifulSoup(response.content, "html.parser")
    print("解析完成")
